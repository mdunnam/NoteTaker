QNote Capture Helper

This desktop helper lives in the system tray, keeps a global shortcut registered, and opens the same QNote capture flow in your default browser.

Ctrl/Cmd + Shift + Space
  • Leave this helper running in the tray while you want the shortcut active.
  • Left-click the tray icon to open capture immediately.
  • Use the tray menu to show this window again or quit the helper.
  • If Ctrl/Cmd + Shift + Space is already taken, the helper falls back to another available shortcut.
  • The helper opens /capture?source=desktop-hotkey in your normal browser session, so it can reuse existing QNote auth.
  • Override the target with QNOTE_DESKTOP_CAPTURE_URL if your app is not running at http://127.0.0.1:3000/capture.
  • Override the shortcut with QNOTE_DESKTOP_CAPTURE_SHORTCUT if you want a fixed custom binding.
Rust tooling is required to build this helper. On Windows, install Rust, WebView2, and the Visual C++ build tools before running the Tauri scripts.
